## 📖 Sobre el proyecto

Este repositorio contiene el proyecto práctico del **Curso Práctico de Maquetación y Animaciones con CSS** de [Platzi](https://platzi.com), impartido por Estefany Aguilar. El objetivo es construir un landing page interactivo aplicando maquetación moderna y animaciones dinámicas.

## ✨ Lo que se construye

- ⏳ **Loader** animado con HTML y CSS
- 🧱 **Layout** estructurado con CSS Grid
- 🧭 **Navbar** con Flexbox y Grid, con animaciones
- 📰 **Contenido principal y lateral** con cuadrículas y estilos complejos
- 🦶 **Footer** con animaciones CSS
- 🪟 **Modal interactivo** usando el DOM y eventos de clic en JavaScript
- 🎠 **Carrusel de imágenes** con CSS y JavaScript

## 🧠 Conceptos practicados

| Área                | Temas                                                  |
| ------------------- | ------------------------------------------------------ |
| 🎯 Maquetación      | CSS Grid, Flexbox, posicionamiento absoluto y relativo |
| 🎬 Animaciones      | `@keyframes`, `transition`, `transform`                |
| ⚙️ JavaScript       | Acceso al DOM, eventos, manipulación de clases         |
| 📐 Buenas prácticas | Estructura HTML semántica, organización de proyecto    |

## 🛠️ Tecnologías
